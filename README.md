# Tkinter GUI of 3ma to OBJ Converter

## What is this?
This is a GUI for the 3ma to OBJ Converter. It allows users to convert 3ma files to OBJ format using a simple and user-friendly interface.

## Whats a 3ma file?
3ma files are a 3D file used from an Android App called 3D Model App. It is a proprietary format used by the app to store 3D models and scenes. The 3ma file format is not widely supported by other 3D modeling software, which is why a converter is needed to convert it to a more widely used format like **OBJ**. Furthermore, 3ma files are json based, which means they can be easily read and modified using a text editor or programming language. This makes it possible to extract the 3D model data from the 3ma file and convert it to an **OBJ** file.

## How to use the GUI
1. Download the 3ma to OBJ Converter GUI from the repository's releases.
2. Run the executable file.
3. Select the 3ma file you want to convert.
4. Choose the location where you want to save the converted OBJ file.
5. Click the "Convert Now" button to start the conversion process.
